# Home Screen — Page Flip Demo

Live interactive prototype of the Home screen with a page-by-page "flip up" transition.

## View locally
Just open `index.html` in a browser (Home.svg must sit in the same folder).

## Deploy with GitHub Pages
1. Create a new GitHub repo (e.g. `home-flip-demo`).
2. Upload `index.html` and `Home.svg` to the repo root.
3. Go to repo **Settings → Pages**.
4. Under "Build and deployment", set **Source: Deploy from a branch**, **Branch: main**, folder **/(root)**.
5. Save. GitHub will give a link like:
   `https://<your-username>.github.io/home-flip-demo/`
6. Share that link with the client.
